# Security

## Scope

Security-relevant defects include memory/bounds errors, malformed-input handling, unsafe file/config persistence, privilege or service-control mistakes, unsafe diagnostic/device actions, and any condition where untrusted input can cause unintended code, data or system modification.

## Reporting

Do not publish sensitive exploit details in a public issue. Use GitHub private vulnerability reporting/security advisories when available.

Provide the affected revision, environment, reproduction, expected/observed behaviour and impact boundary.

## Response

Reproduce, add regression coverage where practical, fix the underlying contract and validate the affected environment.

## Supported source

Current main and the current release line are the primary maintained sources unless documented otherwise.
